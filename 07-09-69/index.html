แนวคิด Mobile-First

เริ่มออกแบบและเขียนโค้ดสำหรับหน้าจอมือถือก่อน จากนั้นจึงเพิ่มเงื่อนไขสำหรับหน้าจอที่ใหญ่ขึ้น

ข้อดี

  • เว็บไซต์โหลดเร็ว
  • เหมาะกับผู้ใช้มือถือ
  • โค้ดเป็นระเบียบ

การใช้งานจริง

ใช้ร่วมกับ Responsive Design และเป็นมาตรฐานของการพัฒนาเว็บยุคปัจจุบัน

Responsive Images

ตัวอย่างรูปภาพที่ปรับขนาดตามหน้าจอโดยอัตโนมัติ ไม่ล้นจอ และไม่เสียสัดส่วน

Modern CSS Features

ตัวอย่างนี้แสดงการใช้ CSS Variables และฟังก์ชัน clamp() เพื่อทํา Responsive Design โดยไม่ต้องเขียน Media Query จํานวนมาก

เมื่อขยายหรือย่อหน้าจอ จะเห็นว่าระยะขอบและขนาดตัวอักษร ปรับเปลี่ยนอย่างอัตโนมัติและลื่นไหล
